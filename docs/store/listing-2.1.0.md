# App Store listing 2.1.0

Only "What's new" changes; the rest of the listing (name, subtitle, description, keywords, screenshots) stays as in
`listing-2.0.0.md`. Its line "Wikipedia entera o los artículos esenciales, según tu espacio" stays true: the kit
proposes the top articles and the whole Wikipedia is one tap away in the Library (`docs/ESSENTIAL_CONTENT.md`).

If 2.1.0 replaces 2.0.1 in review (2.0.1 never released), add the last line of each block too.

## What's new in 2.1.0

**es:**

```
Nomad Pocket 2.1 prepara tu kit en mucho menos espacio.

• El kit inicial descarga lo esencial de cada colección: primeros auxilios, supervivencia, huerto, reparaciones y libros de texto
• Wikipedia: los 50.000 mejores artículos completos (1,2 GB) en lugar de 13 GB. La completa sigue en la Biblioteca
• Nada se descarga dos veces: las guías que ya están dentro de otra no se vuelven a bajar
```

```
Nomad Pocket 2.1 sets up your kit in far less space.
```
