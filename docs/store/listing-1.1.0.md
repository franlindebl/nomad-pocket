# App Store listing — 1.1.0 (approved by the owner 2026-10-27)

Draft of the App Store Connect texts for version 1.1.0, second pass 2026-10-27: the owner
wants the listing aimed at the moment the internet goes down (blackouts, crises, infrastructure
failures, cyberattacks), with a stronger hook, including a new name. Nothing here is in App Store
Connect yet; the owner approved these texts on 2026-10-27 (docs/RELEASE.md). es-ES and es-MX share the Spanish texts,
en-US and en-GB the English ones; keywords stay per locale (the Spain store indexes es-ES + en-GB, the
US store en-US + es-MX, so pairs shouldn't repeat words, nor words already in the name or subtitle).

Plan: 1.0.1 (build 3) waits for App Review's answer about monetization; once it is approved, a 1.1.0
version is created and submitted with these texts, the latest build (22: build 21 plus the right
neighbourhood on search results) and the new screenshots. The name and
subtitle change with the 1.1.0 version (changing them now would touch the 1.0.1 under review).

Limits: name 30, subtitle 30, promotional text 170, description 4000, keywords 100, what's new 4000.

## App Review notes

```
Nomad Pocket is completely free: no in-app purchases, no subscriptions, no ads, no accounts and no paid content. It has no server of its own and makes no money; it is an open source project (GPL-3.0, https://github.com/franlindebl/nomad-pocket). All content is free, openly licensed public data downloaded from its original public servers: Wikipedia and other archives from Kiwix and its mirrors, OpenStreetMap maps and routing packages built from OpenStreetMap and published on the project's GitHub Releases, and optional open AI models from Hugging Face.

How to review: no sign-in is needed. On first launch, pick a country (preselected from the device region) and the app proposes a kit sized for the free space; downloading it takes a few minutes on Wi-Fi (a small country such as Andorra downloads in seconds). After that, everything works in airplane mode: the map with routes and search, Emergency (nearby hospitals, pharmacies, water…), the library reader, the AI assistant and Preparedness.

Permissions: location (while in use) shows the user on the offline map and sorts emergency points by distance. Microphone and speech recognition are used only when the user taps the dictate button in the assistant; recognition runs on the device (requiresOnDeviceRecognition) and nothing is stored or sent. Notifications are local reminders for expiry dates in the emergency bag checklist. The app never accesses the photo library (the purpose string is there because a bundled library references the Photos framework).

The AI assistant runs on the device (Apple Intelligence when available, otherwise a downloadable open model through llama.cpp); nothing is sent to any server. Medical content shows a "not medical advice" notice.
```
