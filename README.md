# Nomad Pocket

**Knowledge that never goes offline — in your pocket.**
*El conocimiento que nunca se desconecta, en tu bolsillo.*

Nomad Pocket is an open-source iOS and Android app that brings the idea of
[Project N.O.M.A.D.](https://github.com/Crosstalk-Solutions/project-nomad) to mobile:
download what matters while you have a connection, then use it anywhere, with no
internet at all.

- 📚 **Library** — Wikipedia, medical references, survival and DIY guides, books (Kiwix ZIM files)
- 🗺️ **Offline maps** — cut any region from the OpenStreetMap/Protomaps planet, GPS and pins
- 🎓 **Courses** — educational content with progress tracking
- ✨ **Local AI assistant** — on-device model that answers from your library, with sources
- 🛟 **Preparedness** — family emergency plan, kit checklist sized to your household with expiry reminders, printable PDF
- 🌍 Spanish and English, light and dark themes

![Nomad Pocket screens](docs/screenshots/overview.png)

## Status

Version 1.0.2. All four modules work end to end on iOS (iPhone and iPad) and Android:
catalog + downloads (pause/resume, background on iOS, fastest Kiwix mirror), ZIM reader
with full-text search and table of contents, on-device map extraction + offline
rendering, courses with progress, and the local assistant (Apple Intelligence, Gemini
Nano or llama.cpp GGUF models) answering from your library with citations. iOS builds
go to TestFlight / the App Store; Android is not published yet. Details, backlog and
known limits: [docs/PROGRESS.md](docs/PROGRESS.md).

## Development

```bash
npm install            # also fetches the libkiwix iOS xcframework (postinstall)
npx expo run:ios       # or: npx expo run:android  (dev build; Expo Go won't work)
npm test               # unit tests (pmtiles, OPDS, RAG, HTML, markdown…)
npx tsc --noEmit && npx expo lint && npm run check:i18n
npm run check:catalog  # checks every catalog download URL
npm run e2e            # Maestro functional suite on the iOS simulator
```

Building iOS from the command line: pass `-packageAuthorizationProvider netrc` to
`xcodebuild`, otherwise SwiftPM can block on a Keychain prompt.

Requires Xcode 26+ (iOS 27 simulator for Apple Intelligence), Android Studio (SDK, NDK,
its JBR as `JAVA_HOME`) and Node 22.6+. Native code lives in `modules/` (local Expo
modules); `ios/` and `android/` are generated by `expo prebuild`.
